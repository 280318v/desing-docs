\section{運用・保守・セキュリティ対策}
\subsection{運用}
運用の項目として以下が考えられる.
\begin{itemize}
    \item サーバの起動・停止・再起動など，基本的な運用管理を行う．

    \item システムの稼働状況を常時監視し，障害発生時には運営担当者へ迅速に報告・共有する体制を整備する．

    \item 主な利用者が高齢者であることを踏まえ，問い合わせ窓口では平易な表現での案内を心がけ，必要に応じて問題の切り分けや報告を行う．

    \item 投稿された内容を定期的に確認し，誤った操作案内や不適切な投稿を発見した場合は，非表示化・削除などの対応を行う．

    \item タイアップ企業との連携投稿について, 掲載内容や掲載期間を管理し,「PR」である旨の表示が維持されているかを確認する.

    \item ユニコインやポイントの付与・消費の記録を監視し，不正な取得や残高の不整合が生じていないかを確認する．

    \item 定期的にデータのバックアップを実施し，障害発生時には迅速な復旧が可能な体制を整える．

    \item 機能追加や改善に伴うアップデートを行う際は，トラブル発生時の復元が可能となるよう，事前にバックアップデータを保存する．
\end{itemize}
\subsection{保守}
保守の項目として以下が考えられる.
\begin{itemize}
    \item 運用中に発生した不具合を確認し, 原因を特定の上で修正を行う.

    \item システム障害が発生した場合には, 迅速に復旧対応を実施する.

    \item サービス継続性を高めるため, 障害時にも稼働を維持できる構成を検討する.

    \item AI検索機能やAIキャラクター育成機能で利用する大規模言語モデル（LLM）のAPI, およびタイアップ企業等の外部サービスについて, 仕様変更や提供停止に備え, 定期的に接続状況や応答を確認する.

    \item 利用者の増加や投稿データの蓄積に応じて, 検索機能の応答速度が低下しないよう, 動作状況を監視し必要な改善を行う.

    \item セキュリティ向上および安定稼働を目的として, OSやソフトウェアを常に最新版へ更新する.

    \item バグ報告や機能改善要望, 不適切な投稿の通報を受け付ける窓口を設置し, 対応状況を管理する.

    \item ネットワークやハードウェア障害など, 専門的な対応が必要な場合は外部業者に委託する.
\end{itemize}
